# 002. 전처리에서 AI 잡음 제거를 빼고 동적 음량 보정만 사용

- 날짜: 2026-10-28
- 상태: 채택 (v2.1)

## 배경
원거리 녹음이라 소리가 작고 잡음이 많음. v2에서 ffmpeg `afftdn`(잡음 제거) + `dynaudnorm`(동적 음량 보정)을 함께 넣었음.

## 근거
- 의료 음성 500개, ASR 모델 4개(Whisper 포함)로 실험한 연구: 잡음 제거를 거친 쪽이 **40개 조합 전부에서 원본보다 오류율이 높았음**(절대 1.1~46.6%p 증가). 요즘 ASR은 이미 잡음에 강하고, 잡음 제거가 인식에 필요한 음성 특징까지 지운다는 해석. (arXiv 2512.17562)
- SAM-Audio 잡음 제거 + Whisper: 소리 품질 지표(PSNR)는 올랐지만 **Whisper 오류율은 모든 조건에서 상승**. (arXiv 2603.04710)
- 전체 볼륨을 올리는 건 잡음도 같은 비율로 키우고, Whisper가 내부에서 상대값으로 처리하므로 효과가 거의 없음.
- 동적 음량 보정은 교수님이 돌아서거나 목소리가 작아진 구간만 키워서 원거리 강의 녹음에 의미가 있음.

## 결정
- `preprocess_filter`: `highpass=f=80,lowpass=f=7600,dynaudnorm=f=150:g=15`
- 동적 음량 보정은 무음 구간 잡음도 키워 환각 위험이 있으므로 `hallucination_silence_threshold`와 함께 사용

## 결과
- v1에서 완전히 무너졌던 8:24~8:51 구간이 v2.1에서 정상 문장으로 복구됨.
- 가장 큰 개선은 여전히 녹음 단계(앞자리, 교탁 근처 기기, 핀마이크)에서 나옴.
