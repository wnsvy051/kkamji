# 001. 전사 엔진으로 로컬 Whisper(mlx-whisper) 선택

- 날짜: 2026-10-28
- 상태: 채택

## 배경
- AI 채팅 모델에 mp3를 주면 원문 대신 요약을 돌려줌. 긴 오디오는 출력 길이 한계로 줄여 쓰고, "전사"를 "정리"로 넓게 해석함.
- 4과목 × 주 2회 × 75~90분 ≈ 주 600~720분을 전사해야 함.

## 검토한 선택지
| 선택지 | 판단 |
|---|---|
| LLM 채팅에 mp3 직접 | 요약으로 빠짐. 10~15분씩 잘라 넣어도 반복 작업이 많고 누락 발생 |
| A 앱 내장 전사 | 원거리 녹음에서 인식률이 너무 낮음 (전공 용어 대부분 오인식, 반복·깨진 문자) |
| B 서비스 (클라우드 전사) | 의미 정확도는 좋지만 개인용 무료 한도가 월 수백 분이고 추가 구매가 어려움 → 첫 주에 한도 소진 |
| **로컬 Whisper** | 무료·무제한·오프라인. 맥 GPU로 빠름 |

## 결정
- 엔진: OpenAI Whisper `large-v3-turbo` (정확도 large-v3의 약 95%, 약 8배 빠름)
- 구현체: `mlx-whisper` (Apple MLX, GPU 사용)
  - `faster-whisper`는 맥에서 Metal 빌드가 없어 CPU로만 동작 → 제외
  - `whisper.cpp`도 후보였으나 파이썬 통합·후처리 편의로 mlx-whisper 선택
- 한국어는 SenseVoice가 더 빠르지만 정확도는 Whisper가 높음(CER 5.59% vs 8.28%) → Whisper 유지
- LLM은 전사가 아니라 그 다음의 정리·요약 단계에만 사용

## 결과
- 89분 강의에서 용어 정확도·분량은 B 서비스를 앞섬. 문장 의미 정확도는 일부 구간에서 B 서비스가 우세 → 핵심 공식 등은 교재로 검증 필요.
