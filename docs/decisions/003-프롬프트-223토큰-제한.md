# 003. 용어 힌트 프롬프트는 223토큰 안에서 최근 챕터 우선

- 날짜: 2026-10-28
- 상태: 제약 확인, 용어 파일 설계는 제안 단계

## 확인한 사실
- mlx-whisper 0.4.3 `decoding.py`: `prompt_tokens[-(self.n_ctx // 2 - 1):]` → `initial_prompt`는 **마지막 223토큰만** 사용되고, 넘치면 **앞부분부터 잘림**.
- Whisper 다국어 토크나이저로 측정: 한국어 약 0.8토큰/자 → **약 250~270자가 한도**.
- 현재 과목별 프롬프트: 104~115토큰.

## 영향
- 챕터마다 용어를 계속 덧붙이면 한도를 넘고, 문장 앞쪽(오래된 용어)이 조용히 버려짐.
- 교정 규칙(`term_fixes`)은 사후 처리라 길이 제한이 없음.

## 방향
- 과목별 용어 파일(`용어/<과목>.txt`)에 챕터 단위로 기록
- 프롬프트는 **파일 아래쪽(최근 챕터)부터 채우고** 한도를 넘는 옛 용어는 제외
- 교정 규칙은 계속 누적
- 새 오인식은 Claude 과목 프로젝트에서 전사본을 정리할 때 함께 뽑아 추가
