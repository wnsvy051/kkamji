# 깜지 (Kkamji)

> 강의 녹음을 **요약 없이, 한 글자도 빠짐없이** 원문 그대로 전사하는 로컬 파이프라인

AI 채팅에 강의 녹음을 주고 "그대로 받아 적어줘"라고 하면 요약본이 돌아옵니다.
시험 공부에 필요한 건 교수님이 실제로 한 말 전부입니다. 깜지는 **전사 전용 엔진(Whisper)으로 원문을 받아 적고**, 정리·요약은 그 다음 단계로 분리합니다.

- **완전 로컬**: Apple Silicon 맥에서 실행. 녹음이 기기 밖으로 나가지 않음
- **무료·무제한**: 최대 n분 제한 및 유료 플랜의 한도 문제 해결
- **폴더에 넣기만 하면 끝**: 과목 폴더에 녹음을 넣으면 자동 전사, 완료 시 알림
- **강의 특화 후처리**: 환각 문구 제거, 반복 정리, 과목별 전공 용어 자동 교정

## 결과 (89분 운영체제 강의, 같은 녹음으로 비교)

| | A 앱 | Whisper v1 | **깜지 v2.1** | B 서비스 |
|---|---|---|---|---|
| 받아 적은 분량(글자) | 22,593 | 34,497 | **38,318** | 28,941 |
| 깨진 문자 | 41 | 74 | **0** | 0 |
| 반복("아 아 아 아") | 15 | 7 | **0** | 4 |
| DMA 정확 / 오인식 | 6 / 1 | 14 / 3 | **28 / 0** | 10 / 19 |
| 디바이스 드라이버 정확 / 오인식 | 4 / 9 | 9 / 5 | **16 / 0** | 3 / 17 |
| 처리 시간 | - | 약 25~30분 | **약 4분** | - |

강의실 마이크 없이 맥으로 원거리 녹음한, 음질이 좋지 않은 녹음 1개로 비교한 결과입니다. 녹음 환경에 따라 결과가 달라질 수 있어 각 서비스의 일반적인 성능을 뜻하지는 않습니다.
자세한 비교는 [docs/experiments](docs/experiments/2026-10-28_도구비교_89분강의.md)에 있습니다.

## 동작 방식

```
녹음(mp3) ──▶ 넣는곳/<과목>/ ──(launchd 폴더 감시)──▶ 전처리(ffmpeg)
   ──▶ Whisper large-v3-turbo (mlx-whisper, 과목별 용어 힌트)
   ──▶ 후처리: 환각 제거 · 반복 정리 · 용어 교정
   ──▶ 전사본/<과목>/YYYY-MM-DD_파일명.txt  +  맥 알림
```

주요 결정의 근거는 [docs/decisions](docs/decisions/)에 있습니다.

## 요구 사항

- Apple Silicon 맥 (M1 이상)
- [Homebrew](https://brew.sh)
- 디스크 여유 약 3GB (Python 패키지 + Whisper 모델 약 1.6GB)

## 설치

```bash
git clone https://github.com/wnsvy051/kkamji.git
cd kkamji
bash scripts/install.sh
```

처음 한 번만 Python 3.12, ffmpeg, mlx-whisper, 모델을 내려받습니다.
다시 실행하면 이미 받은 건 건너뛰고 코드·설정만 갱신합니다. 전사가 진행 중이면 설치가 멈춥니다.

## 사용법

```
~/강의전사/
├── 넣는곳/<과목>/    ← 녹음 파일을 여기에
├── 전사본/<과목>/    ← 결과
├── 원본/<과목>/      ← 처리 끝난 녹음
├── 실패/<과목>/
├── 로그/transcribe.log
└── config.json
```

```bash
tail -f ~/강의전사/로그/transcribe.log    # 진행률 (5%마다)
```

> ⚠️ 바탕화면·문서·다운로드·iCloud 폴더는 macOS 보안 정책 때문에 백그라운드 작업이 읽지 못합니다. 녹음은 반드시 `~/강의전사/넣는곳/` 안에 넣으세요.

### 설정 (`~/강의전사/config.json`)

| 키 | 설명 |
|---|---|
| `model` | 기본 `whisper-large-v3-turbo`. 더 정확하게: `mlx-community/whisper-large-v3-mlx` |
| `prompts` | 과목별 용어 힌트. **약 223토큰(한국어 250자 내외)까지만** 쓰이고 넘치면 앞부분이 잘림 |
| `term_fixes` | 과목별 `{정규식: 바꿀 말}`. 위에서부터 순서대로 적용 |
| `preprocess` | 저주파 컷 + 동적 음량 보정. AI 잡음 제거는 [역효과 근거](docs/decisions/002-잡음제거-제외.md)로 제외 |
| `temperature` | 인식이 애매한 구간의 재시도 단계. 줄일수록 빠름 |
| `prevent_sleep` / `ac_power_only` / `notify` | 잠자기 방지 / 전원 연결 시에만 / 맥 알림 |

### 해제

```bash
bash scripts/uninstall.sh    # 자동 감시만 해제, 전사본·녹음은 유지
```

## 개발

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

후처리(환각 제거, 반복 정리, 용어 교정)는 Whisper 없이 텍스트만으로 테스트합니다.
**강의 녹음과 전사본은 저장소에 올리지 않습니다** (`.gitignore`). 테스트에는 직접 만든 텍스트 조각과 직접 녹음한 몇 초짜리 음성만 씁니다.

## 주의

강의 녹음은 교수님의 허락이 필요할 수 있고, 녹음·전사본을 공유·배포하면 저작권·초상권 문제가 생길 수 있습니다. 깜지는 **개인 학습용**을 전제로 합니다.
